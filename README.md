# java-racingcar-precourse

# 프로젝트 개요
사용자가 입력한 자동차 이름과 시도 횟수를 기반으로 자동차 경주 게임을 구현한다.
자동차는 전진 또는 멈출 수 있으며 경주 종료 후 우승자를 출력한다.

# 구현 기능 목록
1. 입력 처리
- camp.nextstep.edu.missionutils.Console.readLine()을 사용해 사용자 입력을 받는다.
- 자동차 이름은 쉼표(,)로 구분되며 각 이름은 5자 이하만 가능하다.
- 시도 횟수는 1 이상의 정수만 입력 가능하다.

2. 예외 처리
- 자동차 이름이 5자를 초과한 경우 IllegalArgumentException을 발생한다.
- 자동차 이름이 비어 있거나 공백인 경우 예외를 발생한다.
- 시도 횟수가 숫자가 아니거나 1 미만을 경우 예외를 발생한다.
- 잘못된 입력값에 대해 IllegalArgumentException을 발생시키고 예외 발생 시 애플리케이션은 종료되어야 한다. (System.exit() 사용 금지)

3. 경주 진행
- 각 자동차는 매 시도마다 0~9 사이의 랜덤값을 생성한다. (camp.nextstep.edu.missionutils.Randoms.pickNumberInRange(0, 9) 사용)
- 랜덤값이 4 이상일 경우 전진, 아니면 멈춘다.
- 모든 자동차의 결과를 한 줄씩 출력한다.

4. 출력
- 각 시도별 실행 결과를 출력한다.
- 모든 시도가 끝나면 최종 우승자를 출력한다. (우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.)
